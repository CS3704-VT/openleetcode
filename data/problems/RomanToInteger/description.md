# Roman To Integer

This problem converts a string of Roman numerals into an integer. 

Examples:
"III" -> 3
"LVIII" -> 58
"MCMXCIV" -> 1994

Constraints:
1 <= s.length <= 15
s contains only the characters ('I', 'V', 'X', 'L', 'C', 'D', 'M').
It is guaranteed that s is a valid roman numeral in the range [1, 3999].
