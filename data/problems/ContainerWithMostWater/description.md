# Container With Most Water

**Difficulty:** Medium

**LeetCode:** https://leetcode.com/problems/container-with-most-water/

Given an integer array `height`, representing the heights of vertical lines, find two lines that form a container holding the maximum amount of water.

Return the maximum area.

## Input

An array of integers representing the heights.

## Output

An integer representing the maximum area.

## Constraints

- 2 <= height.length <= 100000
- 0 <= height[i] <= 10000

## Example

Input: `[1,8,6,2,5,4,8,3,7]`

Output: `49`
