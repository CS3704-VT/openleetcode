# Valid Anagram

Given two strings ``s`` and ``t``, return ``true`` if ``t`` is an anagram of ``s``, and ``false`` otherwise. The input consists of two lowercase strings ``s`` and ``t`` and the output is a boolean.
\
\
\
**Example 1:**

>**Input:** s = "anagram", t = "nagaram"\
>**Output:** true

**Example 2:**

>**Input:** s = "cali", t = "california"\
>**Output:** false

**Example 3:**

>**Input:** s = "abb", t = "aab"\
>**Output:** false

**Constraints:**

* ``1 <= s.length, t.length <= 5 * 10^4``
* ``s`` and ``t`` consist of lowercase English letters.
