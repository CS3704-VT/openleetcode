# Valid Anagram
**LeetCode:** https://leetcode.com/problems/valid-anagram/

**Difficulty:** Easy

## Description

Given two strings, `s` and `t`, return `true` if `t` is an anagram of `s`, and `false` otherwise.
An anagram uses the same letters the same number of times, but they can be in a different order.

## Examples:

**Example 1**
Input: `s = "anagram", t = "nagaram"`
Output: `true`

**Example 2**
Input: `s = "rat", t = "car"`
Output: `false`

## Constraints
- Both strings contain between 1 and 50,000 characters.
- Both strings contain lowercase English letters.
