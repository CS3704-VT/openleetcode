# Reverse Bits

Reverse the bits of a given 32-bit integer ``n`` and return the result.
\
\
\
**Example 1:**

>**Input:** n = 43261596\
>**Output:** 964176192\
>**Explanation:** 43261596 is ``00000010100101000001111010011100`` in binary. Reversed, that is ``00111001011110000010100101000000``, which is 964176192.

**Example 2:**

>**Input:** n = 2147483644\
>**Output:** 1073741822\
>**Explanation:** 2147483644 is ``01111111111111111111111111111100`` in binary. Reversed, that is ``00111111111111111111111111111110``, which is 1073741822.

**Constraints:**

* ``0 <= n <= 2^31 - 2``
* ``n`` is even.
